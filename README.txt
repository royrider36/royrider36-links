IMPORTANT:
This is a ready-to-publish website, not yet online. The QR code should be created
only after you publish the site and have its final public URL.

Free publishing option:
1. Create/sign in to a GitHub account.
2. Create a new public repository named royrider-links.
3. Upload index.html and the assets folder (keep the same folder structure).
4. In repository Settings > Pages, select deploy from branch, choose main and / (root), then save.
5. GitHub Pages will provide the public website URL. Use that final URL to create the QR code.

Before printing the QR code, test all three buttons on a phone. If any social account uses a different profile URL, replace that URL in index.html first.
